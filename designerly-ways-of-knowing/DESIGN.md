# Designerly Ways of Knowing

This inquiry is a dependency-free static site for GitHub Pages. It has three connected modes:

- Presentation: a 29-step evidence-led argument in reading or projection display.
- Explore: question-led routes into 45 concepts and 64 typed relations.
- Democracy Labs: an orientation-led case explorer with instances, research conditions, journeys, comparisons, filters, evidence statuses and explicit gaps.

`data/content.json` is an allowlisted export of the `public` object in the approved content model. Rendering logic is in `app.js`. `reading.html` is a complete static and printable route generated from the same public records. The interactive index contains meaningful HTML before scripts run and links to the reading route when scripts are unavailable.

URL state uses `v=1`, preserves mode namespaces during cross-mode travel, and shares presentation steps, Explore selections, case records, journey stop IDs, filter arrays, comparisons and evidence depth. Case filters use OR within each facet and AND across facets. Selected records remain open when filters exclude them.

The visual system uses semantic HTML, thin rules and labelled relations. It has no remote fonts, runtime libraries, copied diagrams, participant media or slide-derived images. Essential qualifications remain adjacent to claims. Colour and line style never carry meaning alone.

Do not edit public claim wording or relation strength without updating and revalidating the private evidence and content contracts. Do not add raw research records, consent material, private paths or uncertain-rights media to this directory.
